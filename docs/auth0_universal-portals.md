# auth0 universal-portals

Set up and audit Auth0 Universal Portals.

These commands run a tool that is built into the CLI. It needs Node.js 20.12 or newer, and it calls the
Auth0 Management API as the tenant you are logged in to.

## Commands

- [auth0 universal-portals audit](auth0_universal-portals_audit.md) - Check a Universal Portal
- [auth0 universal-portals setup](auth0_universal-portals_setup.md) - Set up a Universal Portal
