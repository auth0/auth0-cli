# auth0 actions modules show

Display the code, dependencies, secrets, and version information about an action module.

## Usage
```
auth0 actions modules show [flags]
```

## Examples

```
  auth0 actions modules show
  auth0 actions modules show <module-id>
  auth0 actions modules show <module-id> --json
```


## Flags

```
      --json           Output in json format.
      --json-compact   Output in compact json format.
```


## Inherited Flags

```
      --debug           Enable debug mode.
      --no-color        Disable colors.
      --no-input        Disable interactivity.
      --tenant string   Specific tenant to use.
```
