# auth0 plugins available

List the plugins published in the signed Auth0 CLI plugin registry. The registry index is signature-verified before it is read.

## Usage
```
auth0 plugins available [flags]
```

## Examples

```
  # List every plugin published in the registry
  auth0 plugins available
```




## Inherited Flags

```
      --agent-mode      Output JSON, disable prompts and colors. Auto-enabled for AI agents; set AUTH0_AGENT_MODE=false to disable.
      --debug           Enable debug mode.
      --no-color        Disable colors.
      --no-input        Disable interactivity.
      --tenant string   Specific tenant to use.
```
